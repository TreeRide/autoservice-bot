# ServiceBot — отказоустойчивая экосистема автоматизации для современных автосервисов

Проект объединяет умного Telegram-бота на базе асинхронного фреймворка Aiogram 3.x и высокопроизводительное веб-приложение (Telegram Mini App / CRM) на FastAPI.
Система автоматизирует весь цикл взаимодействия с клиентом: от ИИ-распознавания документов (OCR) по фотографии и ведения цифровой сервисной книжки до построения сложной матрицы расписания мастеров с гибкими графиками и защитой от пересечений.

## 🚀 Архитектурные особенности и ключевой функционал

### 1. Интеллектуальный модуль ИИ (OCR документов)
* Глубокая интеграция с Google Gemini API (`google-generativeai`).
* Клиент или мастер отправляет фотографию СТС, техпаспорта или документа на автомобиль.
* Нейросеть автоматически извлекает структурированные данные: марку, модель, год выпуска, VIN-код, тип топлива и объем двигателя, заполняя профиль транспортного средства «в один клик».

### 2. Панель управления для мастеров и администраторов (CRM Mini App)
* **Динамическая матрица расписания:** интерактивный календарь с таймслотами по оси Y и мастерами по оси X.
* **Защита от коллизий (Overlap Protection):** алгоритмы исключают наложение записей по времени и загрузке постов.
* **Гибкий график работы:** индивидуальная настройка смен для будней, субботы и воскресенья, а также точечные календарные оверрайды (праздники, отгулы, усиленные дни).
* **Walk-in флоу (Ручная запись):** мгновенное создание записи администратором как по существующим клиентам (с интеллектуальным поиском по базе), так и оформление «с нуля».
* **Управление статусами заявок:** сквозная связка входящих заявок (новые, просмотренные/в обработке) с календарными слотами и фиксацией комментариев (причин визита).

### 3. Пользовательский интерфейс (Клиентский Гараж)
* Личный кабинет внутри Telegram Mini App.
* Мультигараж: привязка и управление несколькими автомобилями одного владельца.
* Электронная сервисная книжка и прозрачная история обслуживания.
* Интерактивная онлайн-запись на свободные интервалы времени.

### 4. Фоновые процессы и отказоустойчивость
* **Умный ежедневный планировщик:** фоновый asyncio-цикл, проверяющий сроки и пробег автомобилей по графику (`Europe/Minsk`), с автоматической отправкой срочных и просроченных напоминаний (система дедупликации уведомлений).
* **Персистентное хранилище FSM (`SQLiteStorage`):** кастомная реализация `BaseStorage` для Aiogram, сохраняющая состояния диалогов в ту же SQLite БД. Переживает любые перезапуски сервера без потери контекста пользователей.
* **Динамические меню:** разделение интерфейса на уровне Telegram Bot API — клиенты видят кнопку «Сервисная книжка» (WebApp), а администраторы перенаправляются в CRM-дашборд.
* **Глобальный обработчик ошибок (`@dp.errors`):** перехват исключений с отправкой диагностических логов администраторам и возвратом понятных сообщений пользователю.

## 🛠 Технологический стек
* **Язык:** Python 3.10+
* **Telegram Bot:** Aiogram 3.27+ (Long-polling, Middlewares, FSM)
* **Backend API / Mini App:** FastAPI, Uvicorn, Pydantic v2
* **База данных:** SQLite (WAL mode, `synchronous=NORMAL`), SQLAlchemy 2.0 (AsyncIO)
* **Миграции БД:** Alembic (с умным автоопределением legacy-схем и stamp-механизмом)
* **ИИ / LLM:** Google Gemini SDK
* **Фронтенд Mini App:** HTML5, Tailwind CSS, Vanilla JavaScript, Telegram WebApp SDK

## 📂 Структура репозитория
```text
├── main.py              # Точка входа бота: запуск polling, фоновых задач и миграций
├── config.py            # Конфигурация, таймзоны (ZoneInfo) и переменные окружения
├── startup.py           # Инициализация базы данных, WAL-режима и bootstrap админов
├── fsm_storage.py       # Персистентное хранилище FSM aiogram поверх SQLite
├── notifications.py     # Фоновый планировщик ежедневных пуш-уведомлений
├── filters.py           # Кастомные фильтры aiogram (проверка прав администратора)
├── states.py            # FSM-группы состояний для клиентских и админских сценариев
├── alembic.ini          # Конфигурация миграций базы данных
├── alembic/             # История миграций схемы БД
├── database/            # Асинхронный слой данных (модели SQLAlchemy и репозитории)
├── handlers/            # Роутеры и логика диалогов Telegram-бота
├── middlewares/         # Middleware для инъекции сессий БД и управления FSM
└── web_app/             # FastAPI бэкенд, эндпоинты CRM, шаблоны и фронтенд Mini App
```
## ⚙️ Установка и локальный запуск
### 1. Клонирование репозитория и установка зависимостей
```bash
git clone https://github.com/TreeRide/autoservice-bot.git
cd treeride-autoservice-bot

# Создание и активация виртуального окружения
python -m venv .venv
source .venv/bin/activate  # Для Linux/macOS
# .venv\Scripts\activate   # Для Windows

# Установка зависимостей
pip install -r requirements.lock.txt
```
2. Настройка окружения (.env)
Создайте файл .env в корне проекта и заполните его необходимыми параметрами:
```env
BOT_TOKEN=7123456789:AAH...                  # Токен вашего бота от @BotFather
WEBAPP_URL=https://your-domain.com           # Публичный HTTPS URL для Mini App (например, через Cloudflare/Ngrok)
ADMIN_BOOTSTRAP_IDS=123456789,987654321      # Telegram ID администраторов (через запятую)
GOOGLE_API_KEY=AIzaSy...                     # Ключ для работы Google Gemini OCR
APP_TZ=Europe/Minsk                          # Таймзона приложения
```
3. Запуск бота
При первом запуске приложение автоматически применит миграции Alembic, включит режим SQLite WAL и выполнит bootstrap администраторов:
```bash
python main.py
```
